# HabitFlow

HabitFlow is a habit tracking web application designed to help users build consistency, improve productivity, and maintain positive daily routines.

## Features
- Add and manage daily habits
- Track streaks and completion progress
- Mood tracking system
- Activity heatmap
- Progress dashboard
- Responsive UI design
- User login and email verification
- AI-based motivational quotes based on user mood

## Tech Stack
- HTML
- CSS
- JavaScript
- Local Storage
- Supabase Authentication

## Future Improvements
- Cloud syncing across devices
- Advanced analytics dashboard
- Habit reminder notifications
- Gamification and rewards system
- Mobile app version

## How to Run
1. Download or clone the repository
2. Open the folder in VS Code
3. Run `index.html`
